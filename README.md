# Personal Portfolio Website

A responsive static portfolio website built with HTML, CSS, and JavaScript.

This project was created as a hands-on front-end and Git/GitHub practice project, with multiple iterations focused on layout, styling, navigation, and portfolio presentation.

- Responsive landing page
